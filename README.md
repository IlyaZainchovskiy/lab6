# Практична робота 6

## Варіант завдання
Додаток **"Кулінарна книга"** (управління рецептами та категоріями страв)

---

## 🛠 Технології

- Мова: **C# (.NET)**
- UI фреймворк: **Windows Forms**
- ORM: **Entity Framework Core (Microsoft.EntityFrameworkCore.SqlServer)**
- База даних: **Microsoft SQL Server (LocalDB)**

---

## 📋 Опис завдання та архітектури

### 1. База даних та моделі (EF Core)

Додаток використовує підхід **Code-First**.  
База даних створюється автоматично при запуску програми за допомогою:

- `EnsureDeleted()`
- `EnsureCreated()`

Також база заповнюється початковими даними (**Seed Data**):
- 3 категорії
- кілька рецептів

Реалізовано зв’язок **"один-до-багатьох"**:

#### Category (Категорія)
- Id
- Name  
- Колекція Recipes

#### Recipe (Рецепт)
- Id  
- Title  
- Description  
- CookingTimeMinutes  
- CategoryId (зовнішній ключ)

---

### 2. Синхронізація інтерфейсу

Головне вікно реалізовано через **TabControl** із трьома вкладками.

Додаток забезпечує повну синхронізацію даних:
будь-які зміни (додавання, редагування, видалення) миттєво відображаються у всіх вкладках.

---

## 💻 Огляд інтерфейсу користувача (UI)

### 📌 Вкладка 1: Управління рецептами (CRUD)

Реалізовано повний цикл роботи з даними:

- ListBox для вибору рецепта (через DataSource)
- Поля редагування:
  - Назва (TextBox)
  - Опис (TextBox)
  - Категорія (ComboBox)
  - Час приготування (NumericUpDown)
- Кнопки:
  - Додати
  - Редагувати
  - Видалити

Операції виконуються через `db.SaveChanges()`.

---

### 📌 Вкладка 2: Перегляд (ListView)

- Відображення даних у режимі **Details**
- Рядки формуються вручну через `ListViewItem`
- Дані беруться з колекції рецептов

---

### 📌 Вкладка 3: Перегляд (DataGridView)

- Табличне відображення даних
- Використовується `DataSource`
- Для уникнення проблем EF Core використовується проекція через `LINQ (.Select())` у DTO-формат

---
