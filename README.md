База даних та Моделі (EF Core)Додаток використовує підхід Code-First. База даних генерується автоматично при запуску програми (EnsureDeleted() та EnsureCreated()) і заповнюється початковими даними (Seed data: 3 категорії та кілька рецептів).Реалізовано зв'язок "один-до-багатьох":Category (Категорія): має CategoryId, Name та колекцію рецептів.Recipe (Рецепт): має RecipeId, Title, Description, CookingTimeMinutes та зовнішній ключ CategoryId.2. Синхронізація ІнтерфейсуГоловне вікно складається з компонента TabControl із трьома вкладками. Додаток гарантує синхронізацію: будь-які зміни даних (додавання, редагування, видалення) на першій вкладці миттєво відображаються на двох інших.Огляд інтерфейсу користувача (UI)Вкладка 1: Управління рецептами (CRUD)Тут реалізовано повний цикл управління даними:ListBox для вибору рецепта (завантажується через DataSource).Поля для редагування: назва (TextBox), категорія (ComboBox), час приготування (NumericUpDown), опис/інгредієнти (багаторядковий TextBox).Кнопки: Додати, Редагувати, Видалити, які викликають db.SaveChanges().Вкладка 2: Перегляд (ListView)Дані з бази даних виводяться за допомогою компонента ListView у режимі Details.Заповнення рядків відбувається шляхом ручного перебору колекції та створення об'єктів ListViewItem.Вкладка 3: Перегляд (DataGridView)Дані відображаються в таблиці DataGridView.Для коректної роботи (без нескінченного зациклення через навігаційні властивості EF Core) колекція проектується в анонімний тип (DTO) за допомогою LINQ-запиту (.Select(...)) перед прив'язкою до DataSource. Як запустити проектВідкрийте рішення у Visual Studio.Переконайтеся, що встановлено NuGet-пакет Microsoft.EntityFrameworkCore.SqlServer.Запустіть програму (клавіша F5).
